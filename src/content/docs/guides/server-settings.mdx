---
title: Server settings
description: Configure leaderboards and command availability for a server.
---

Run `/server settings` in a server. You need Discord's **Manage Server** (`ManageGuild`) permission.

- **Public leaderboard** determines whether the server leaderboard can be viewed publicly. It is private by default.
- **Disabled commands** cannot be used in the server.
- **Admin-only commands** remain available only to server administrators.

Command restrictions start empty. Disabling a command removes it from the admin-only list, and making it admin-only removes it from the disabled list, so the two states do not conflict.
