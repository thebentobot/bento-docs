---
title: Getting started
description: Invite Bento and run your first slash command.
---

1. [Invite Bento to your Discord server](https://discord.com/api/oauth2/authorize?client_id=787041583580184609&permissions=1644167687254&scope=bot%20applications.commands).
2. In a channel where Bento can respond, type `/` and select a Bento command.
3. Try `/about bento`, `/profile user`, or `/lastfm save`.

Discord shows required options first and offers choices or autocomplete where the command supports them. Commands labelled **Server only** cannot be used in direct messages.

Need a hand? Join the [Bento support server](https://discord.gg/dd68WwP).
